## Summary

Appointment booking with pluggable providers (ClinicCards live; Google Calendar / Calendly planned), Gutenberg / shortcode / Elementor, and a Notifications tab (email, Telegram, form forwarding).

Version **0.4.1** is the directory-approved package after one review round (not first-pass).
