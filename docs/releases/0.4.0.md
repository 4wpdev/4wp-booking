# 4WP Booking 0.4.0

**Published:** 2026-09-07  
**Plugin:** https://4wp.dev/  
**GitHub:** https://github.com/4wpdev/4wp-booking

## Summary

Appointment calendar for WordPress with pluggable providers — now with a dedicated Notifications tab for email, Telegram, and form forwarding.

## Highlights

- Notifications tab: email and Telegram for new bookings
- Optional form → Telegram for Contact Form 7, WPForms, and Gravity Forms (shared bot token; separate chat IDs with fallback)
- Clear non-affiliation: not WordPress, not ClinicCards

## Longer post (blog / newsletter)

**4WP Booking** helps visitors book appointments from Gutenberg, a shortcode, or Elementor. Version **0.4.0** adds a first-class **Notifications** screen: email and Telegram for bookings, plus optional forwarding of Contact Form 7, WPForms, and Gravity Forms submissions to Telegram using the same bot setup.

4WP is our brand. The plugin is not affiliated with WordPress or with ClinicCards; ClinicCards remains an optional provider via their public API.
