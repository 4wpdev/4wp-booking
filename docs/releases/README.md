# Release notes (4WP Booking)

Draft copy for channels **outside** WordPress.org — Google Business Profile, social, newsletter, [4wp.dev](https://4wp.dev/), etc.

WordPress.org users see [readme.txt](../../readme.txt) (`== Changelog ==`).

## Workflow

1. Ship the version (Git tag; SVN when listed).
2. Add `{version}.md` here.
3. Paste or adapt into each channel.
4. **Publish on Google Business Profile → Updates / News** (manual).

## Not shipped in wp.org ZIP

This `docs/` tree is excluded via [.distignore](../../.distignore).

Do **not** skip Google Business Profile for “small” or SVN-only releases.
