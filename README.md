# 4WP Booking

Public WordPress plugin: native appointment calendar with pluggable providers.

- **Live provider:** ClinicCards (optional; not affiliated)
- **Planned:** Google Calendar, Calendly
- **Surfaces:** shortcode `[forwp_booking]`, Gutenberg block `forwp/booking`, Elementor widget (optional)
- **Notifications:** email, Telegram; optional form → Telegram (CF7, WPForms, Gravity Forms)

Directory listing copy: [readme.txt](readme.txt). Release drafts: [docs/releases/](docs/releases/).
